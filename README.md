# Sistem Informasi Presensi Madin Nawwir Quluubana

Selamat datang di *repository* resmi **Aplikasi Presensi Madrasah Diniyah (Madin) Nawwir Quluubana**.

Aplikasi ini adalah platform berbasis web (Web Application) yang dibangun untuk memudahkan administrasi madrasah, khususnya dalam mengelola kehadiran santri secara modern, terpusat, dan terintegrasi.

## 🌟 Fitur Utama

- **Manajemen Data Master**: Pengelolaan data Santri, Ustadz, Majelis, dan Kitab dengan mudah.
- **Presensi Digital Harian**: Memungkinkan asatidz untuk menginput kehadiran santri di setiap majelis.
- **Validasi Izin (Sakit/Izin)**: Santri dapat mengajukan izin tidak hadir, dan asatidz dapat melakukan validasi persetujuan secara real-time.
- **Laporan & Rekapitulasi**: Fitur pembuatan laporan kehadiran santri secara otomatis dalam format Tabel web, Cetak langsung, maupun *Export* PDF.
- **Dokumentasi Pembelajaran**: Pengarsipan foto dokumentasi untuk setiap majelis.
- **Hak Akses Berlapis (Role)**: Memiliki tampilan dan fitur khusus yang disesuaikan untuk peran **Admin**, **Ustadz**, dan **Santri**.
- **Desain Responsif**: Antarmuka (*User Interface*) yang ramah pengguna, modern, dan sangat nyaman dibuka di layar HP (Mobile-friendly) maupun Laptop/PC (Desktop).

---
*Dibangun dengan Laravel & Tailwind CSS.*
